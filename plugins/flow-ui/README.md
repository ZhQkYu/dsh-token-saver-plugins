# @dsh-plugins/flow-ui

The browser half of the flow plugin: a "Flow" sidebar entry and a main panel that lists and (in the editor milestone) edits flows. All Host interaction goes through the `@dsh-plugins/flow` Connection routes.

## Status

Under construction. The flow list page and sidebar entry are in place (M0/M1). The canvas editor is the next milestone.

## Build

```bash
pnpm run build   # bundles src/client/index.tsx into lib/client.js
```
